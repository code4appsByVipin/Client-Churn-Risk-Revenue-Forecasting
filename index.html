How I prepared and scored the data

    Example SQL aggregation

    This example groups billing, support and service records by client and month. I did not run it on real data.

    WITH imputed_billing AS (
  SELECT client_id, month_start,
         COALESCE(net_amount, tier_service_median,
                  service_median, global_median) AS amount_filled,
         CASE WHEN net_amount IS NULL THEN 1 ELSE 0 END AS amount_missing
  FROM billing_transactions
),
client_month AS (
  SELECT client_id, month_start,
         SUM(amount_filled) AS monthly_spend,
         AVG(amount_missing) AS missing_financial_share
  FROM imputed_billing
  GROUP BY client_id, month_start
)
SELECT client_id, month_start, monthly_spend,
       missing_financial_share
FROM client_month;

    What the estimates mean

      Use with care

      • I use simulated client records. They do not describe real clients or support client-specific decisions.
      • I assume the annual churn risk is spread evenly across months. Renewal timing may differ.
      • The forecast leaves out new clients, expansion, price changes, currency changes and non-churn revenue losses.

      Tools used

      • Vite builds the static site.
      • Chart.js draws the charts. PapaParse reads the CSV files.
      • SQL/Spark appears only in the example aggregation query.
      • XGBoost scores churn risk. SHAP explains the report model results.
